# RSE España - Web Page

Este directorio contiene los archivos base para lanzar la página web fundacional de RSE España usando GitHub Pages.

## Cómo desplegar la web:

1. Crea una organización en GitHub (ej. `rse-es`).
2. Crea un repositorio llamado `rse-es.github.io`.
3. Sube el archivo `index.html` directamente a la rama `main` o `master` de ese repositorio.
4. ¡Listo! En unos minutos tu web estará disponible en `https://rse-es.github.io`.

## Personalización
- Puedes editar la sección de "Nuestra Visión" en el `index.html` para incluir los logos de instituciones afiliadas cuando tengas los primeros socios.
- El enlace de "Firma el Manifiesto" asume que tendrás un repositorio llamado `manifiesto` donde los miembros puedan hacer un Pull Request para añadir su firma. ¡Asegúrate de crearlo!
